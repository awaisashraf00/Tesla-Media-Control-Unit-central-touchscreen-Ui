# Music Files Directory

Place your MP3 music files here with the following names:
- track1.mp3
- track2.mp3
- track3.mp3

You can add your own music files or download royalty-free music from sources like:
- YouTube Audio Library
- Free Music Archive
- Incompetech

## Note
The music controller will automatically play these tracks in sequence.
You can modify the track names and metadata in `src/MusicController.cpp`.
